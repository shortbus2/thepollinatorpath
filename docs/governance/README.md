## Start here

The Pollinator Path is a living ecological garden record. Governance exists to protect real observations, ecological context, stable identities, media evidence, and the human meaning of the garden across releases and technical changes.

Read [PROJECT_CHARTER.md](./PROJECT_CHARTER.md) first for the mission and governing commitments. Use [RECONCILIATION.md](./RECONCILIATION.md) when establishing the historical baseline.

## Governing rule

> Never lose information that represents a real observation.

When evidence conflicts, preserve it, explain it, and obtain human approval. Do not silently overwrite history.

## Status

These files are currently a preview governance foundation. They do not approve reconciliation decisions, authorize dataset generation, or permit repository or production changes.
